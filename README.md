# Проект для керування бізнесу по управлінню книжкового клубу із можливістю не лише придбати книги, але й брати на прокат книги та настільні ігри

## Основні Фунції:
### 1) Управління каталогами книг та настільних ігор
* Перегляд книг за жанрами, авторами, роками видань, ціною
* Перегляд ігор за віковими обмеженнями, кількістю гравців, ціною
### 2) Оформлення та контроль оренди
* Фіксація дати взяття в оренди та створення дати, коли предмет мають повернути 
### 3) Інформація про співробітників
### 4) Оформлення постійного кліента
* Оформлення картки, збереження персональних даних
* Нарахування та накопичення бонусів
### 5) Обробка продажів 
* Оформлення покупок 
### 6) Клубні зустрічі 
* Планування зустрічей  з відношенням до конкретної книги чи гри 
* Прив'язка співробітника до подіх
